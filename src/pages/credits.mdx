# Credits

This website was made from scratch by myself using the [Astro](https://astro.build/) framework. The source code is available on [Codeberg](https://codeberg.org/louiszn/louiszn.fyi).

The current layout is heavily inspired by [petrapixel](https://petrapixel.neocities.org/), though the site was written from scratch without inspecting its source code.
