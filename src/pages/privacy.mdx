<h1 class="text-center">Privacy</h1>

## THIS WEBSITE DOESN'T TRACK YOU!

There are no analytics, advertising trackers, fingerprinting, or third-party cookies used here.

This website is intentionally minimal because collecting personal information about visitors doesn't benefit me in any way. And I don't like building profiles about who's visiting my site either. This is my little corner of the internet, after all. >:3

This site is mostly static because, honestly, why would I need JavaScript to render pages that don't change? I'm also targeting old devices and slow internet to have this site loaded just fine!

## What about visit counter?

This is the only component on this website that uses JavaScript so far. It is just a simple visit counter with a single visit:count field stored on my self-hosted Redis server.

I've also implemented some basic anti-spam measures, such as rate limiting and localStorage to prevent the browser from making unnecessary requests.

It's purely decorative and serves no real purpose at all!
